\#Delete Element in Array


\### 📌 Problem Statement

Write a Java Program to create a Array and take the input array size and elements from the user and Delete a element in array as user enter's.


\### 📥 Sample Output

```text
Enter a Array size :
5
Enter 5 Elements in Array  :
10 20 30 40 50
Array Elements :
10 20 30 40 50
Enter Element want to Delete:
30
Array After Element Deletion :
10 20 40 50 0
